# BeagleBoard Kernel Repository Comparison

## **https://github.com/beagleboard/linux**

This is "The official Read Only BeagleBoard and BeagleBone kernel repository" that mirrors the main development at https://git.beagleboard.org/beagleboard/linux. This repository contains:

- **BeagleBoard.org's official kernel** with BeagleBoard-specific patches and configurations
- **Mainline-based approach**: "bb-kernel: based on mainline, no-smp, optimized for AM335x devices"
- Contains `bb.org_defconfig` files for various BeagleBoard platforms
- Features "the latest configuration files and patches for the various BeagleBone Black platforms"

## **https://github.com/beagleboard/mirror-ti-linux-kernel**

This is a "Mirror of: https://git.ti.com/gitweb?p=ti-linux-kernel/ti-linux-kernel.git;a=summary" - essentially Texas Instruments' official kernel tree. This repository contains:

- **TI's BSP (Board Support Package) kernel**
- **TI-focused approach**: "ti-linux-kernel-dev: based on TI's git tree, smp, optimized for AM335x/AM43xx/AM57x devices"
- More comprehensive TI SoC support beyond just BeagleBoard devices
- May include TI-specific drivers and optimizations that haven't been upstreamed

## **Key Differences**

### **Target Audience**

- **beagleboard/linux**: Specifically optimized for BeagleBoard/BeagleBone users
- **mirror-ti-linux-kernel**: Broader TI processor ecosystem (AM335x, AM43xx, AM57x, etc.)

### **Base & Features**

- **beagleboard/linux**: Mainline-based, single-core optimized (no-smp)
- **mirror-ti-linux-kernel**: TI BSP-based, multi-core support (smp enabled)

### **Patch Philosophy**

- The BeagleBoard repository serves "users who expect backward compatibility to early beagleboard.org firmwares"
- TI's repository "provide[s] additional things, like the accelerated 3D graphics drivers, which are proprietary"

## **Recommendation**

**For your BeagleBone Black project**, the **beagleboard/linux** repository is likely the better choice since it's specifically maintained for BeagleBoard devices and includes the tested configurations and patches that the BeagleBoard.org community relies on.
