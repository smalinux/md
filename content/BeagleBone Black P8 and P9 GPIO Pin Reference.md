## Notes:

- GPIO references are for device tree usage
- Many pins have alternative functions (PWM, SPI, I2C, UART, etc.)
- Always check pin multiplexing configuration when using GPIO
- Power and ground pins cannot be used as GPIO
- ADC pins (AIN0-AIN6) are analog inputs, not GPIO
